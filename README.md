Donde la Chiky — E-commerce Platform

Plataforma de comercio electrónico moderna, rápida y responsiva diseñada a medida para **Donde la Chiky** (Iquique / Alto Hospicio), enfocada en la venta de cosmética, perfumería y accesorios.

🔗 **Sitio en producción:** [donde-la-chiky.vercel.app](https://donde-la-chiky.vercel.app)

---

### ✨ Características Principales
- **Catálogo Dinámico:** Navegación fluida por categorías, novedades y productos destacados.
- **Buscador Integrado:** Búsqueda rápida de artículos en tiempo real.
- **Carrito de Compras / Bolsa:** Gestión ágil de pedidos para clientes.
- **Panel Administrativo (`/admin`):** Módulo de gestión interna para control de productos y catálogo.
- **Opciones de Entrega:** Configuración para retiros en tienda y delivery local (Iquique y Alto Hospicio).
- **Diseño UI/UX Responsivo:** Interfaz moderna y adaptada a dispositivos móviles con paleta de colores personalizada (Dark Mode accent).

---

### 🛠️ Stack Tecnológico
- **Frontend & Framework:** Next.js (React)
- **Estilos & Diseño:** Tailwind CSS, PostCSS
- **Gestor de Paquetes:** Yarn
- **Despliegue & Hosting:** Vercel (CI/CD automático desde rama `main`)
